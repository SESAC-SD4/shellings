## 새 명령: `find`

`find 폴더 -name "패턴"`은 폴더 안을 **안쪽 폴더까지** 뒤져서 이름이 맞는 파일을 찾습니다.

```
find . -name "*.txt"
```

`.`은 지금 폴더, `"*.txt"`는 `.txt`로 끝나는 모든 이름입니다. 패턴은 따옴표로 감싸세요.

## 상황

`notes`와 `archive` 폴더 안에 폴더가 여러 겹 있고, 여기저기에 `.md` 기록과 다른 파일이 섞여 있습니다.

## 할 일

연습 폴더 안의 **모든 `.md` 파일 경로**를 `filelist.txt`에 저장하세요. `.md`가 아닌 파일은 들어가면 안 됩니다.
